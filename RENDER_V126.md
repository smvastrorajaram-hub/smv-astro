# Render deployment — V126

1. Push this project to GitHub.
2. Create a Render Web Service from the repository (or use the included render.yaml if you prefer Blueprint deployment).
3. Build command: `npm install`
4. Start command: `npm start`
5. Node version: 20 or newer.
6. No Swiss Ephemeris files or `SWISSEPH_EPHE_PATH` are required.

Keep your existing Firebase/Razorpay/Email secrets in Render Environment Variables.
